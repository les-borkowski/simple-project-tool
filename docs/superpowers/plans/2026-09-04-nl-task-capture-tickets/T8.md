# T8 — UI: quick capture modal

[← index](README.md) · source: [full plan](../2026-09-04-nl-task-capture-and-eval-harness.md)

---

**Type:** frontend
**Goal:** from the project board, a user types a sentence, reviews what was understood, and creates
the tasks in one pass.
**Difficulty:** medium
**Depends on:** T5
**Acceptance criteria:**
- [ ] A "Quick capture" action on the project board opens a modal with a textarea and a submit
- [ ] Submitting shows the extracted tasks as an editable review list — title, due date, assignee,
      story — with per-task checkboxes; **low-confidence tasks start unchecked**
- [ ] "Create" posts only the checked tasks to the confirm endpoint, then refreshes the board;
      cancelling creates nothing
- [ ] Unparseable / not-a-task responses show the warning and keep the user's text so they can edit
      and retry; 503s show a distinct "capture is unavailable" message
- [ ] A pending state is shown during the call, and the submit is disabled while in flight
- [ ] Every string is in `frontend/src/locales/en-GB.json` **and** `pl.json`; the modal is usable at
      375px and in both themes
**API contract:** *identical to the block in T4 — copy it verbatim.* Consumes both
`POST /api/v1/projects/{project_id}/tasks/capture` and `…/capture/confirm`.
**Files in scope:** `frontend/src/components/capture/QuickCaptureModal.tsx` (+ review list),
`frontend/src/services/api.ts` (`captureApi`), the project board page,
`frontend/src/locales/{en-GB,pl}.json`, a Vitest test alongside the component.
**Constraints:** reuse the existing modal/sheet primitives from the mobile rework — do not hand-roll
another overlay. Tap targets and type scale follow the established tokens.
**Verification:** `npm run lint && npm run build`, the Vitest test, and a browser pass at 375px and
1280px in light and dark.
**Out of scope:** any backend change; a standalone capture page; keyboard shortcut to open the modal.
