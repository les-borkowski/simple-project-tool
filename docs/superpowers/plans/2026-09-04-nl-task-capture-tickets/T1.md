# T1 — LLM client interface, Gemini adapter, replay client

[← index](README.md) · source: [full plan](../2026-09-04-nl-task-capture-and-eval-harness.md)

---

**Type:** backend
**Goal:** the app can ask a language model for schema-constrained JSON through an interface that
names no vendor, and can replay recorded responses instead of calling out.
**Difficulty:** medium
**Depends on:** none — foundation, justified: both the endpoint and the eval harness sit on it.
**Acceptance criteria:**
- [ ] `LLMClient` Protocol with one method:
      `async def complete(system: str, user: str, *, json_schema: dict | None = None, max_tokens: int, temperature: float) -> LLMResponse`;
      `LLMResponse` carries `text`, `model`, `prompt_tokens`, `completion_tokens`, `latency_ms`
- [ ] `GeminiClient` posts to `generativelanguage.googleapis.com/v1beta/models/{model}:generateContent`
      with `x-goog-api-key`, sets `responseMimeType: application/json` and `responseSchema`, and reads
      `candidates[0].content.parts[0].text` + `usageMetadata`
- [ ] `schema_adapter.to_gemini_schema()` converts a Pydantic `model_json_schema()` into the OpenAPI
      subset: `$ref`/`$defs` inlined, `anyOf: [T, null]` collapsed to `T` + `nullable: true`,
      `additionalProperties` dropped — unit-tested against the real `ExtractionResult` schema
- [ ] `ReplayClient(fixtures_dir)` returns the recorded response for
      `sha256(provider|model|prompt_version|system|user)` and raises a named `FixtureMissError`
      naming the key on a miss; it never constructs an HTTP client
- [ ] `get_llm_client()` selects on `settings.LLM_PROVIDER`; an empty `GOOGLE_API_KEY` raises a
      typed `LLMNotConfigured` rather than making a doomed request
- [ ] HTTP 429 is retried up to 3 times honouring `Retry-After`; timeouts and 5xx raise
      `LLMUnavailable`
**Files in scope:**
`app/core/llm/__init__.py` (factory), `base.py` (Protocol, `LLMResponse`, exceptions),
`gemini_client.py`, `schema_adapter.py`, `replay.py`, `prompts.py` (`PROMPT_VERSION` constant only —
the prompt text lands in T2); `app/core/config.py` (+5 settings); `backend/.env.example`;
`tests/test_llm_client.py`.
**Constraints:**
- Follow `app/core/email.py`: raw `httpx`, **no vendor SDK**, config through the existing `Settings`
  class. `pyproject.toml` must gain no new runtime dependency.
- New settings exactly: `LLM_PROVIDER=google`, `LLM_MODEL=gemini-2.5-flash`, `GOOGLE_API_KEY=`
  (empty default), `LLM_TIMEOUT_SECONDS=30`, `LLM_CAPTURE_MIN_CONFIDENCE=0.5`.
- No API key value in the repo, in a test, or in `.env.example`.
**Verification:**
- `uv run pytest tests/test_llm_client.py` — transport stubbed with `httpx.MockTransport`
- **One live smoke, run by hand and recorded in the PR description:** a real call with a real key
  that returns JSON conforming to the adapted schema. This is the ticket's real acceptance test —
  the schema-subset mismatch (§2.8) will only show up here.
**Out of scope:** prompts, the capture schema, anything under `app/api/`.
