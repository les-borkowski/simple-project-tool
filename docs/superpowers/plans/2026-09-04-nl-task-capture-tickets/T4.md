# T4 — `POST …/tasks/capture` — preview endpoint

[← index](README.md) · source: [full plan](../2026-09-04-nl-task-capture-and-eval-harness.md)

---

**Type:** backend
**Goal:** a caller submits free text to a project and gets back structured, review-ready tasks with
assignees and stories resolved to real ids — and nothing is written.
**Difficulty:** medium
**Depends on:** T2
**Acceptance criteria:**
- [ ] The endpoint builds `ProjectContext` from the DB (project name, member display names, story
      names) and returns the contract below
- [ ] `assignee_hint` resolves against project members case-folded on name, then email local-part;
      an ambiguous or unmatched hint yields `assignee_id: null`, `assignee_resolved: false` and a
      warning — never a guess. `story_hint` resolves the same way against story names.
- [ ] `require_project_access()` is enforced; a non-member gets 403 and no model call is made
- [ ] Tasks below `LLM_CAPTURE_MIN_CONFIDENCE` are returned with `low_confidence: true`; the response
      always has `needs_confirmation: true`
- [ ] Unparseable output and not-a-task input both return **200** with `tasks: []` and a warning —
      never a 5xx. Provider down → 503 `LLM_UNAVAILABLE`; no key → 503 `LLM_NOT_CONFIGURED`
- [ ] No row is written by this endpoint under any input — asserted by a test that counts tasks
      before and after
**API contract** *(identical text in T5 and T8)*
```
POST /api/v1/projects/{project_id}/tasks/capture
Auth: JWT bearer, or X-API-Key with scope write:tasks (T6)
Request:
  {"text": str (1..4000), "reference_date": "YYYY-MM-DD"|null, "story_id": uuid|null}
200:
  {"tasks": [{"title": str, "description": str|null,
              "story_hint": str|null, "story_id": uuid|null, "story_resolved": bool,
              "assignee_hint": str|null, "assignee_id": uuid|null, "assignee_resolved": bool,
              "due_date": "YYYY-MM-DD"|null, "priority": "low"|"medium"|"high"|null,
              "confidence": float, "low_confidence": bool}],
   "unparseable": bool, "needs_confirmation": true, "warnings": [str],
   "model": str, "prompt_version": str, "latency_ms": int}
403 FORBIDDEN · 404 PROJECT_NOT_FOUND · 503 LLM_NOT_CONFIGURED | LLM_UNAVAILABLE
A failed extraction is a 200 with tasks: [], never an error status.

POST /api/v1/projects/{project_id}/tasks/capture/confirm
Auth: JWT bearer, or X-API-Key with scope write:tasks (T6)
Request:
  {"tasks": [{"title": str, "description": str|null, "story_id": uuid|null,
              "assignee_id": uuid|null, "due_date": "YYYY-MM-DD"|null,
              "priority": "low"|"medium"|"high"|null}]}   # 1..20 items
201: {"created": [TaskResponse, ...]}      # existing TaskResponse shape, in request order
403 FORBIDDEN | DEMO_ACCOUNT · 404 PROJECT_NOT_FOUND · 422 VALIDATION_ERROR
All-or-nothing: a 4xx creates zero tasks.
```
**Files in scope:** `app/api/routes/tasks.py`, `app/api/schemas/capture.py` (request/response),
`app/api/services/capture_service.py` (context build + hint resolution),
`app/locales/{en-GB,pl}.json` (`LLM_NOT_CONFIGURED`, `LLM_UNAVAILABLE`, `CAPTURE_UNPARSEABLE`,
`CAPTURE_NOT_A_TASK`), `tests/test_api_capture.py`.
**Constraints:**
- Routes handle HTTP only and call the service; permissions are enforced in the service layer
  (`CLAUDE.md`). Errors use the existing `{"error":{"code","message","details"}}` envelope and the
  code must exist in **both** locale files.
- Keep the route in `routes/tasks.py` beside the other task routes; register nothing new in
  `api/main.py`.
- `Depends(get_current_user)` for now — the API-key dependency swap is T6.
**Verification:** `uv run pytest tests/test_api_capture.py`, with the LLM client dependency-overridden
to a replay/stub client so route tests stay offline.
**Out of scope:** creating tasks (T5); API-key auth (T6); UI.
