# T6 — API-key + scope access on the capture endpoints

[← index](README.md) · source: [full plan](../2026-09-04-nl-task-capture-and-eval-harness.md)

---

**Type:** backend
**Goal:** an agent holding a scoped API key can capture and create tasks without a user session —
making the app's API-key feature reachable for the first time.
**Difficulty:** hard — authentication, and this code path has never executed against a route.
**Depends on:** T5
**Acceptance criteria:**
- [ ] Both capture routes use `Depends(require_scope("write:tasks"))` instead of `get_current_user`;
      JWT callers are unaffected (existing tests still pass unchanged)
- [ ] A valid `X-API-Key` with `write:tasks` (or `admin`) succeeds; one with only `read:tasks` gets
      403 naming the missing scope; a revoked key gets 401
- [ ] Project RBAC still applies to the key's owning user — a key cannot reach a project its user
      cannot reach
- [ ] `last_used_at` is actually persisted after a successful key request (today it is set on a
      session the route may never commit — verify with a fresh read, not the same session)
- [ ] `tests/test_api_capture.py` gains the repo's first end-to-end API-key test: mint a key via
      `POST /api/v1/config/api-keys`, then call capture with it
- [ ] No new scope is introduced; `SCOPE_HIERARCHY` and `VALID_SCOPES` are unchanged
**Files in scope:** `app/api/routes/tasks.py`, `app/auth/dependencies.py` (only if a real bug is
found — record it in the PR), `tests/test_api_capture.py`, `tests/test_auth_dependencies.py`.
**Constraints:**
- Scope is `write:tasks` (decision D2). Do **not** wire API-key auth onto any other route in this
  ticket (decision D3) — file a follow-up instead.
- Do not remove the `key_prefix == ""` legacy fallback here; note its cost and leave it.
**Verification:** `uv run pytest tests/test_api_capture.py tests/test_auth_dependencies.py`, plus a
manual `curl -H "X-API-Key: …"` against a running server.
**Out of scope:** extending API-key auth to projects/stories/tasks CRUD; rate limiting; key rotation.
